## 写作规范

1. **记现象，不记猜测**：「真机断网后媒体库显示"暂无内容"」比「可能是错误处理问题」有用。
2. **根因要能复现**：给命令、日志片段、版本号。
3. **对策要可执行**：`adb shell svc wifi disable` 这种，不要"建议补充测试"。
4. **留下反例**：哪些看起来更简洁但会踩坑的写法，写明为什么不能改。
5. **索引同步**：新增文件必须在本表登记，并同步到 `AGENTS.md` §11。
