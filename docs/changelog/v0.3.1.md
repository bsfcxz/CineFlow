## v0.3.1：正式签名 + 三个 Android 架构的完整包

这个版本是个**分发质量版本**：把 v0.3.0 遗留的两个分发问题一次解决。

### 🔐 换成正式签名（v0.3.0 是 debug 签名）

v0.3.0 的 APK 用的是 **Android SDK 公共调试密钥**（`CN=Android Debug`）——
那是"构建成功"但**不可正式分发**的包：无法上架商店，且将来换正式密钥时
用户必须先卸载重装。

本版用自持的 RSA-4096 发布密钥签名，v1/v2/v3 三套签名方案齐全
（现代 Android 校验 v2/v3），有效期 30 年（Android 要求 >25 年）。

> ⚠️ **升级须知：签名变了，必须卸载旧版再装**
> 因为 v0.3.0 是 debug 签名，与本版不是同一个密钥，
> Android 会拒绝覆盖安装（`INSTALL_FAILED_UPDATE_INCOMPATIBLE`）。
> 请先卸载旧版——**这会清掉本地数据**（播放历史、偏好、登录态）。
> 这也是为什么这个版本号必须递增：不能让大家以为可以平滑升级。

### 📱 三个架构都能真正用（不再是空壳）

v0.3.0 只有 arm64 是真的能用，另外两个**能装但播不了**：
它们缺 `libmpv.so`（播放内核）与 `libcineflow_go.so`（Go 核心层），
`MPVLib` 初始化会抛 `UnsatisfiedLinkError`。

本版把 **6 个原生库**（3 架构 × 2 个）补齐：

| 架构 | `libmpv.so` | `libcineflow_go.so` | 说明 |
|---|---|---|---|
| **arm64-v8a** | 11.80 MB | 6.58 MB | 主流手机 |
| **armeabi-v7a** | 11.20 MB | 6.71 MB | 老设备 / 32 位机 |
| **x86_64** | 15.08 MB | 7.15 MB | 模拟器 / x86 平板 |

三个架构的 `libmpv` **同源同版本**（同一份构建产出，已逐字节校验），
且都导出 JNI 桥必需的 `av_jni_set_java_vm`。

> 为什么值得做：不补齐的话，非 arm64 用户装上去会看到
> "应用能开、能登录、能浏览，但一点播放就报错"——
> 这种"半可用"比直接说不支持更糟。

### 🛡️ 让"发错签名"不可能再发生

v0.3.0 那个 debug 签名的包之所以发得出去，是因为
`flutter build apk --release` 在**找不到签名配置时会静默回退 debug 签名**
（只打印一行告警，退出码仍是 0）。也就是说"构建成功" ≠ "产出了可发布的包"。

本版加了两道机械守卫：

- **`tool/verify_signing.ps1`** —— 本地一条命令校验：证书 DN 不得含
  `CN=Android Debug`、必须有 v2/v3 签名。**看退出码**，可进 CI/门禁。
- **`release.yml` 的签名守卫步骤** —— 发布前逐个 APK 校验，
  发现 debug 签名或缺 v2 **直接让发布失败**（对应分发规范 D10：
  不发布含阻塞缺陷的包）。

### 仓库外的密钥管理

签名私钥放**仓库外**（`%USERPROFILE%\cineflow-keystore\`），
`key.properties` 也被 `android/.gitignore` 忽略 —— 双重保证不可能误提交
（`check-secrets` 门禁已实测通过）。

CI 侧把 keystore 以 base64 存进 **GitHub Secrets**（加密存储、不随仓库分发），
`release.yml` 在构建前还原到 `$RUNNER_TEMP` 并**先自检口令可打开**，
拿不到就直接失败——**绝不回退 debug 签名**。

### 改动清单

- `android/app/build.gradle.kts`：接入正式签名配置（三级查找顺序：
  `CF_KEY_PROPERTIES` 环境变量 → 仓库外默认位置 → `android/key.properties`），
  启用 v1/v2/v3；找不到时保留 debug 回退**但打印醒目告警**
- `tool/verify_signing.ps1`：**新增**，APK 签名校验（可进 CI）
- `.github/workflows/release.yml`：还原 keystore + 构建三架构 + 签名守卫
- `android/app/src/main/jniLibs/{armeabi-v7a,x86_64}/`：**新增**两个架构的原生库
- 版本三处同步：`VERSION` / `pubspec.yaml` / `lib/core/version.dart`

### 已知限制（未变）

- 仅 Android，无 iOS / 桌面端
- **无通知栏控制 / 蓝牙耳机键 / 后台播放**（Media3 会话层未实现）
- 无 401 自愈（token 失效需重新登录）
- 播放中可能熄屏（无 WakeLock）
- 115 网盘走非公开接口，存在风控风险
- 转码未接入（实测当前服务器不具备转码能力）

完整改动见 [v0.3.0 → v0.3.1](https://github.com/bsfcxz/CineFlow/compare/v0.3.0...v0.3.1)。
