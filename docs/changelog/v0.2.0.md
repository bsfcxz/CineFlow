## v0.2.0：断网时不再骗你「片库是空的」

这是 CineFlow 第一次公开开源发布。功能上没有新增大块头，
但把几个「看起来能用、其实在骗人」的地方修掉了——最要紧的一个是：
**以前断网你会看到空白首页，以为自己的媒体库是空的。**

> ⚠️ **需要你动手（只影响开发者）**：门禁脚本从 `.sh` 换成了 `.ps1`。
> 如果你之前记的是 `bash scripts/check-docs.sh`，改用
> `powershell -File scripts/check-docs.ps1`。日常使用 App 不受影响。

### 本版亮点

#### 加载失败，终于会说实话了

以前断网打开媒体库，页面显示「该库暂无内容」——其实不是没有内容，
是请求失败了。首页也一样：一个区块挂掉会让整页变成空白，
你完全分不清是网络问题还是片库真的空了。

现在两者区分开了：**失败就显示错误页 + 「重试」按钮**，只有服务器真的没有内容时才显示空态。
首页四个区块各自降级，一个挂了不影响其余三个；全部挂掉才报「网络/服务器不可用」。

#### 剧集的导演，以前全被丢掉了

详情页的演职员只渲染演员，导演信息虽然服务器返回了却被静默丢弃
（实测这一台服务器上 14 条导演数据全部没显示）。现在演员横滑上方会显示
「导演 A / B」摘要行。

#### 起播就上报进度，不再是「播了不算看过」

以前起播不上报，只有播到 10 秒才发第一次进度——短时间退出会丢进度。
现在起播即发 `Sessions/Playing`。实测依据：起播 8 秒时服务器会话已带
`PositionTicks`，而进度周期是 10 秒，说明它只能来自起播上报。

### 其他改进

- **媒体库排序真的能点了**：新增三种排序（名称/评分/最近添加）循环切换。
  顺带修掉一个更深的坑——`SortOrder` 曾被硬编码为升序，导致「最近添加」
  实际返回**最旧**的条目。
- **默认倍速能存了**：播放设置里新增「默认倍速（下次起播）」，以前只有读取没有写入入口。
- **版本号只有一处了**：以前 `VERSION` / `pubspec` / 协议头 / 「我的」页四个地方各写各的
  （0.2.0 / 1.0.0 / 0.1.0 / 0.1.0）。现在统一由 `VERSION` 驱动，并有脚本强制校验。
- 补齐了 14 篇工程文档（架构契约、审查清单、ADR、踩坑索引等）。

### 修好了

- 恢复误删的 `ACKNOWLEDGEMENTS.md`（README 一直在引用它，链接是断的）。
- 清除了入库的个人开发机路径与真机序列号。
- 提交邮箱改为 GitHub 匿名邮箱（公开仓库不再暴露个人邮箱）。

### 升级须知

- **APK 使用 debug 签名**（已知限制，见 AGENTS.md §7.16）：仅供自用与体验，
  **不要用于正式分发**，也无法上架应用商店。
- 仅提供 **arm64-v8a** 单架构包，老设备装不上。
- 已知限制（未修）：无 401 自愈（token 失效需重新登录）、播放中可能熄屏、
  类型/年份筛选仅作用于已加载内容、豆瓣缓存 TTL 未生效。
- 无数据库迁移、无破坏性变更。

完整改动见 [v0.1.1 → v0.2.0](https://github.com/1357980024/CineFlow/compare/v0.1.1...v0.2.0)。
