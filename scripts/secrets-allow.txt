#
# 两种写法：
#   1) 逐行白名单（**推荐**）：<相对路径> :: <该行必须包含的片段>
#      只有「路径 + 片段」同时匹配才放行，同一文件其它行仍被扫描。
#   2) 逐文件白名单：单独一行写相对路径（慎用——该文件会完全失去扫描）
#
# 规则：每条都要能说清「为什么它是安全的」。说不清就别加，去改内容。

# 集成测试 / 真机测试工具的**回环地址**（127.0.0.1）
# ---------------------------------------------------------------------------
# 理由（每条都是"回环地址"，不是用户服务器的内网/公网地址）：
#   · `127.0.0.1` 是 IPv4 **回环地址**（RFC 1122），永远只指向本机，
#     不指向任何外部主机 —— 与"用户自建服务器地址"是两回事。
#   · 用途：集成测试需要一段**能播放的媒体**。手法是
#     `adb reverse tcp:8765 tcp:8765` 把设备端口映射到宿主机的
#     `python -m http.server`（Android 官方推荐的调试方式），
#     因此地址必然是 `127.0.0.1:8765`，且端口是**测试专用**的固定值。
#   · 这些文件是**测试代码与测试工具**，内容是可直接执行的命令；
#     改成占位符会让测试跑不起来，而它们不含任何凭据。
#   · 用**逐行**白名单（而非整文件）：只放行"回环地址"片段，
#     这些文件里若将来混入真实地址，门禁仍能抓到。
